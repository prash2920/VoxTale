# 🎙️ VoxTale – Every Character Gets a Voice

VoxTale is an AI-powered audiobook project that gives every character a unique voice. Simply paste your book text and let AI identify characters, match suitable voices, and generate audio.

## ✨ Features

- 🔍 AI-powered character identification
- ✅ Evidence-based character detail verification
- 🗣️ Automatic dialogue speaker identification
- 🎭 Smart voice matching based on age, gender, and traits
- 🔊 Text-to-speech using ElevenLabs
- ⚡ Audio caching for faster replay
- 🛡️ Backend API handling to keep API keys secure

## 🛠️ Tech Stack

- **Python**
- **Flask**
- **Groq**
- **Exa**
- **ElevenLabs API**
- **HTML, CSS, JavaScript** (Frontend, if used in your implementation)

## ⚙️ How It Works

1. Paste book text into the application.
2. The Flask backend processes the request.
3. AI identifies characters and their dialogues.
4. Character details are checked against the original text.
5. The system selects suitable voices for each character.
6. ElevenLabs generates speech for the selected voices.
7. Generated audio can be cached for replay.
